*Route selected apps outside the tunnel*

Split-Tunneling, listeye eklediğiniz uygulamaların trafiğini tünelin dışına çıkarır:

- **Bypass Yönlendirmesi** — Seçilen uygulamalar fiziksel arayüzünüz veya tercih ettiğiniz ağ arayüzü üzerinden doğrudan çıkar; tünel ayakta kalır, diğer trafik VPN üzerinden akmaya devam eder.
- **Strict Mod** — Seçilen arayüz erişilemez hale gelirse bypass listesindeki akışlar reddedilir; sessizce tünele geri yönlendirilmez.
- **mDNSResponder dahil etme** — Listeye eklenince yerel ad çözümlemesi de seçili arayüzden taşınır.
