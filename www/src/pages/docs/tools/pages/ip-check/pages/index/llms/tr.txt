# IP Adresim

Bağlantınızı internetin gördüğü şekilde — bir web sitesinin IP adresinizden okuyabileceği verileri — gösteren interaktif bir araç:

- **Genel IP** — IPv4 ve IPv6 adresiniz
- **Konum** — IP'nizden türetilen coğrafi konum
- **İSS** — internet servis sağlayıcınız
- **ASN** — ağınızın otonom sistem numarası

Kendi adresinizi doğrulamak için — veya Phantom-WG'ye bağlandığınızda — gerçek IP'niz yerine tünelin çıkış IP'sinin gösterildiğini teyit etmek için kullanın.
