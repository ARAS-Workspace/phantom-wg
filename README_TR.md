# Phantom-WG Provision

Bu dal, Phantom-WG sunucu topolojilerini bulut ortamlarına kuran provision setlerini içerir. Her set kendi dizinindedir ve kendi belgesini taşır.

| Set                                           | Ortam         | Ne kurar                                              |
|-----------------------------------------------|---------------|-------------------------------------------------------|
| [`aws-ec2`](aws-ec2/README_TR.md)             | AWS EC2       | Phantom-WG Modern ve Phantom-Frontmatter, iki düğümde |
| [`hetzner-cloud`](hetzner-cloud/README_TR.md) | Hetzner Cloud | Phantom-WG Modern ve Phantom-Frontmatter, iki düğümde |

Setin belgesi gereksinimleri, çalıştırma adımlarını ve kurulumun kaldırılmasını anlatır.
