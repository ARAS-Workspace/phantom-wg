# Sarı Gelin — Azerbaijani / Anatolian Folk Song

- **Composition**: "Sarı Gelin" (Azerbaijani: *Sarı Gəlin*, سارؽ گلین) —
  traditional folk song
- **Composer**: Traditional / anonymous (folk melody, no individual author)
- **Mode**: Bayati makam
- **Origin**: Shared across the southern Caucasus (present-day Azerbaijan
  and Armenia), Iran, and eastern Anatolia (present-day Turkey); the
  country of origin is contested. All versions share the same melody with
  different lyrics.
- **Theme**: A boy laments an unattainable love — a "fair-haired bride"
  or a "girl from the mountains," depending on the language.
- **Copyright Status (melody)**: Public domain — traditional folk song
  with no individual composer.
